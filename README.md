# 1.3 位置变化快慢的描述——速度 · 可交互课件

高中物理（人教2019版 必修第一册）第一章第 3 节。**单文件 HTML，零外链，断网可开、微信可发。**

主线：**把"位置变化的快慢"从"一段"逼到"一点"。**

19 步 / 8 幕，对齐 45 分钟教案的八个环节：

1. 情境导入：导航上那条红线是位移还是路程；一东一南两个 20 m/s
2. 速度概念的建立：只用位移不行、只用时间也不行（比值定义法）
3. 平均速度：一段（拖 A、B 手柄选段）；平均速度 ≠ 速度的平均
4. 瞬时速度：E 点的"0 ÷ 0"；**两端一起向 E 收拢**（本课核心）；教参表 1-2 真实数据 0.47→0.41；合适 ≠ 最小
5. 速率与"速度"：匀速圆周运动 + 速度计
6. 实验：选带标准（50 cm 内 35~40 点）；实验四步；求 D 点瞬时速度的三种 Δt 选法
7. v–t 图像：描点、平滑曲线、两条迷思、截距外推
8. 小结：一条链带走

## 科学性

物理内核是纯函数 + 149 条断言（`__viz.selfTest()`），其中"速度专项"54 条误差为 0：

- 匀变速直线运动里，一段的平均速度**精确等于**该段中间时刻的瞬时速度（中间时刻法则）
- 含 E 且以 E 为中点的那一段，其平均速度**精确等于** E 点的瞬时速度
- 遮光片模型 v̄(d) = (√(v₀²+2ad) + v₀)/2，d = 0 时精确等于 v₀
- 表 1-2 六组数据原样取自教师教学用书 P28，截距外推得 0.403 m/s（官方给出 0.41）
